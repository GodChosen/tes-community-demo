TES Community coding workshop
Trainer: Osazee Odigie

1. Keep index.html, style.css, script.js and the images folder together.
2. Open index.html in a browser to practise locally.
3. Cheer counts clicks. At five cheers, a special message appears. Reset starts again.
4. For GitHub Pages, upload these files AND the images folder to the repository.
   Keep index.html at the repository's top level. Do not upload the ZIP itself.
5. In Settings > Pages select Deploy from a branch, main, / (root), then Save.
6. Use the URL shown in Pages and wait for deployment before testing.

GitHub account holders must meet its minimum age rules. Under-13 learners practise
locally and observe the trainer publishing from the trainer's account.
